## Discrepancies found and fixed

1. **em base was 16px, source is 15px** (`html { font-size: 10px }`, `body { font-size: 15px }`).
   Every `1.1em` / `1.3em` value rendered ~7% large. Fixed with an opt-in `.sendero-base15` class
   applied to the two new page wrappers (the existing `/` clone is untouched).
2. **Heading tracking missing** — the theme applies `letter-spacing: -2px` to headings. Added,
   scoped to `.sendero-base15`.
3. **Hero container was not centring its children** — `.brx-container { align-items: flex-start }`
   in globals outranked the Tailwind `items-center`. Fixed with an id-scoped rule.
4. **Paragraph rhythm** — the source gives every `<p>` but the last `margin-bottom: 18px`.
5. **Mobile columns did not stack** — Bricks sets `flex-wrap: wrap` below 767px; added, scoped to
   `.sendero-base15 .brx-container` plus `#brxe-movtox` on /contacto. (Deliberately not applied to
   `.brx-section` globally: the hero is a column flex container and wrapping split it into columns.)
6. **Contacto heading rules lost specificity** to `.sendero-root h3` (class vs class+element) — the
   eyebrows rendered at 27px. Rules re-scoped as `.sendero-root .brxe-…`.
7. **Contacto centring was applied at desktop** — `text-align/align-self: center` on the directory
   eyebrows and counters is a mobile-only rule in the source (verified: they sit at x=734 at 1440px).
   Moved into the 478px block.
8. **`#brxe-brunlt` picked up 20px side padding** from the shared `.brx-container` sub-1300px
   fallback; zeroed on mobile to match the source's 389px inner row.

## Known gaps

- No screenshots or pixel diff; all comparisons are geometric/computed-style.
- The infinite slider's motion could not be exercised: `requestAnimationFrame` is frozen in this
  headless pane (verified), so drag/wheel inertia is unverified at runtime. The static layout,
  wheel/drag handlers and the wrap maths mirror `next_infinite_slider.min.js` line for line.
- Tiles hover verified working (`--mouseenter` class applies on `mousemove`).
- Entrance animations are intentionally static, matching the convention already used by the
  existing `/` clone (`BlurReveal` / `LetterLauncher` render the final state).
- Contacto map is a keyless Google Maps iframe, not the source's Elfsight widget (see
  `contacto-f1a77a9c/ARTIFACT_MANIFEST.md`).
- Column split on /contacto differs by 8px (651/773 vs 659/766) because the right column's
  intrinsic content width differs slightly once the source's webfont icons are replaced by SVGs.
