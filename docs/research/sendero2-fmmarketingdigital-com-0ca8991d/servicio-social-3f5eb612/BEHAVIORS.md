# Servicio social — behaviors

- The form exposes the same visible fields and required markers as the source.
- The clone keeps form submission local and displays an inline confirmation instead of posting user data to the source WordPress endpoint.
- Phone pills link to the corresponding source WhatsApp API URLs.
- Shared header/mobile menu/footer/WhatsApp launcher remain interactive.
- The rich-text editor is represented by an accessible multiline field; the source embedded editor iframe and admin bar are not carried over.
